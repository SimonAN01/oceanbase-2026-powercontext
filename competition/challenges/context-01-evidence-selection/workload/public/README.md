# 公开 SciFact 输入

`scifact-sample.json` 来自 [SciFact](https://github.com/allenai/scifact/tree/68b98a56d93e0f9da0d2aab4e6c3294699a0f72e)，包含一个原始 claim 和八篇原始论文摘要。query 和 document ID 与完整评测数据分开。文件只提供 query 与正文，不包含人工 evidence 区间或相关性标注。

SciFact claims 与 evidence 标注采用 CC BY 4.0；论文摘要来源 S2ORC，采用 ODC-By 1.0。来源和对应许可见该固定版本仓库的 README。
